### 正在构建 · Building

Yiyu Works 是一个从精品 Agent Skills 开始的个人工作室。关注独立开发者的产品界面、项目表达和发布流程，让重复工作更容易完成，让成果更容易修改和继续使用。

首批 [十个免费 Skills](https://github.com/yiyu-works/skills) 已发布为 **0.1.0 实验版**，包含工作流程、可编辑模板与本地辅助工具。安装与测试范围见仓库说明，真实项目效果仍在持续验证。

| 方向 | 希望解决的问题 | 进度 |
| :--- | :--- | :--- |
| **项目表达** | README、清晰文案与 HTML 报告 | [免费实验版](https://github.com/yiyu-works/skills) |
| **界面与实现** | 设计探索、前端检查与网页动效 | [免费实验版](https://github.com/yiyu-works/skills) |
| **演示与内容** | 网页演示、图标、封面与视频转文章 | [免费实验版](https://github.com/yiyu-works/skills) |

### 我们的标准 · Principles

- **完整交付** — 写清输入、输出、依赖与适用范围。
- **真实验证** — 用可复现的案例检验效果，记录限制与失败原因。
- **方便修改** — 优先交付可编辑文件，让成果能继续使用。
- **维护有界** — 明确版本、兼容环境和支持期限。
